# Bolu Korsan Taksi

Bolu korsan taksi iki büyük şehrin ortasında, doğa turizmiyle çalışır. Kışın Kartalkaya'daki kayak otellerine, yılın geri kalanında Abant ve Gölcük'e yolcu taşınır. Uçak için yol uzundur: Esenboğa Bolu merkezden 203 kilometre, 2 saat 9 dakika.

Kartalkaya yolu kışın karlıdır ve zincirli araç gönderilir. Yedigöller'e sonbaharda toprak yoldan gidilir; yol durumuna göre uygun araç seçilir. Mudurnu ve Göynük'ün tarihi evleri için yarım gün ayrılır.
